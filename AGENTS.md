# Project instructions

- This `forma` directory is the application repository. Do not initialize Git in the parent `DesignIt` directory.
- Keep this application local. Do not register, publish, deploy, or host it online.
- Work only within the project directory. Do not create project files elsewhere.
- Remove unneeded temporary files after changes or reviews.
- Remove unneeded generated build files before handing off. Keep source changes clean.
- Stop any local server started for testing or development before finishing, and verify that its port is closed.
